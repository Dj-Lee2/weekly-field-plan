# 외부 구성요소 고지

이 프로젝트가 사용하는 외부 구성요소와 라이선스입니다. 각 라이선스 원문은 `npm ci` 후 `node_modules/<패키지>/LICENSE`에서, 폰트는 `public/fonts/OFL.txt`에서 볼 수 있습니다.

## 배포물에 포함되는 것

| 구성요소 | 버전 | 라이선스 | 저작권 |
|---|---|---|---|
| [React](https://react.dev/) (`react`, `react-dom`, `scheduler`) | 19.1.0 / 0.26.0 | MIT | Copyright (c) Meta Platforms, Inc. and affiliates. |
| [Phosphor Icons](https://phosphoricons.com/) (`@phosphor-icons/react`) | 2.1.10 | MIT | Copyright (c) 2020 Phosphor Icons |
| [Pretendard](https://github.com/orioncactus/pretendard) (`public/fonts/PretendardVariable.woff2`) | 1.3.9 | SIL Open Font License 1.1 | Copyright (c) 2021, Kil Hyung-jin, with Reserved Font Name 'Pretendard' (Source Sans·Inter 포함, `OFL.txt` 참조) |
