주간 포장계획 · 작동 초안

카카오톡 수신·발송과 AI 해석은 미연결입니다. 실제 팀 자료 대신 예시로 검토해 주세요. 취합 파일과 공지문은 실제 양식을 받기 전 임시 형식입니다.

1. 설치 없이 확인하기

주간포장계획_작동초안.html을 PC의 Chrome 또는 Edge에서 여세요. ‘예시로 둘러보기’로 시작하면 제출 완료·확인 필요·작업 없음·미제출을 볼 수 있습니다.

계획 입력 → 항목으로 정리 → 정리 결과 수정 → 저장 → 작업 클릭 → 수정/취소 → 취합·공지 → 확정 및 CSV/TXT 내려받기 순서입니다. 이 방식의 데이터는 해당 브라우저 저장소에만 남습니다. 다른 기기·브라우저와 공유되지 않으며 브라우저 데이터 삭제 시 사라집니다.

2. SQLite 로컬 서버로 실행하기

Node.js 22.13 이상을 설치한 후 이 폴더에서 실행합니다. 패키지에는 빌드된 화면이 포함됩니다. 

node server.mjs

주소: http://127.0.0.1:8788
종료: 실행 터미널에서 Ctrl+C
데이터: runtime/weekly-field-plan.sqlite

서버는 127.0.0.1에만 바인딩합니다. 인증이 없는 단일 사용자 초안으로 외부 공개·팀원 접근용이 아닙니다. SQLite는 Node 22에서 실험적 기능 경고가 나올 수 있습니다. 브라우저 파일 버전과 서버 버전의 저장소는 서로 다릅니다.

3. 개발·검증

npm ci
npm test
npm run build
node server.mjs

전달 시점의 검증 결과는 verification.json에 있습니다. 소스·계약은 ZIP에 포함되어 있습니다.

아직 적용하지 않은 것

  • 실제 카카오 대상방·구성원·권한 연동
  • AI 자연어 해석, 메시지 수정 명령 연결
  • 기관의 취합 파일·공지문 양식
  • 자동 발송·독촉·업무 배정
  • 팀용 인증·외부 호스팅·보관기간 정책

화면의 제출자 이름은 수동 표시명이며 카카오 계정 인증을 뜻하지 않습니다. 처음 지정한 계획 주는 한국시간 기준 다음 주 월요일부터 일요일입니다. 작업 날짜가 모호하면 직접 확인하고 저장하세요.
